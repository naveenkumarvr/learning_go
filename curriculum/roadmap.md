# Go Curriculum Roadmap

## Outcome
Progress from Go novice to independent production-grade Go engineer, with specialization in cloud-native platform engineering and AI platform services. Expertise is demonstrated by evidence across design, implementation, testing, debugging, security, release, operations, and maintenance—not by finishing a list.

## How to use the roadmap
Each section file describes the scope, prerequisites, outcomes, topics, and three section-level capstones. Each topic has a separate specification under `projects/topics/` containing three progressive projects. Section capstones integrate multiple topics. The three final capstones integrate the full curriculum.

## Recommended sequence
Follow sections in order initially. If a validation exposes a prerequisite gap, temporarily study the missing topic, complete its remediation, then return to the original sequence. Section/week numbers are tracking aids, not calendar deadlines.

## Final capstones
- Cloud-Native Platform Controller
- Production AI Inference Gateway
- AI Platform Control Plane

## Reference policy
Prefer the official Go documentation, package documentation, language specification, Go blog, and focused technical references. Use paid learning resources only when they add clear value.
